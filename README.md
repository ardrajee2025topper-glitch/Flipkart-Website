#Flipkart Website Clone  
A frontend project inspired by the Flipkart website, created to practice and improve my web development skills.  
##About the Project  
This project is a website designed using HTML5, CSS3 and Bootstrap. I focused on creating a familiar e-commerce layout with product sections,  
navigation, images, and different webpage components.  
##Technologies used  
-HTML5  
-CSS3  
-Bootstrap  
##Features  
-Navigation bar  
-Product section & categories  
-Images & Product layouts  
-Styled buttons  
-E-commerce inspired user interface  
**What I Learned    
While building this project, I practiced:  
*Structuring webpages using HTML  
*Styling layouts using CSS3  
*Working with images&    
*Creating navigation  
*Organizing a front-end project  
*Using GitHub to manage and publish my project
